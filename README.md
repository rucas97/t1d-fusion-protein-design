# T1D Tri-Functional Fusion Protein Design

Computational design of a beta-cell-targeted fusion protein combining
GLP-1R agonism (Exendin-4), ER-stress protection (MANF), and Treg
recruitment (Fcµ), connected by a beta-cell-optimized protease-responsive linker.

## Hypothesis
A single molecule with a PC2-cleavable linker will simultaneously target
beta cells, suppress autoimmunity, and promote survival, with spatial
activation in the islet microenvironment.
